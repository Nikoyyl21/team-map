# 团队技术图谱

基于公开资料整理的国内基模与多模态团队技术脉络。只写方向与方法，不写在招信息。

## 结构

| 分组 | 内容 |
| :--- | :--- |
| 多模态与视频生成 | 公开技术报告、代表工作、方法演进 |
| 后训练与对齐 | 公开论文、方法族谱 |
| 文本大模型 | 架构与训练方法的公开资料 |
| 语音与 Infra | 公开系统与技术报告 |

## 更新规则

1. 每条结论标注公开来源。
2. 不确定的写「未查到」并标注可信度。
3. 同名歧义列出候选条目，不合并。
4. 不写任何非公开的团队内部信息。

## 说明

这是骨架文件，分组和字段都可以按你的习惯调整。内容以公开论文、技术报告、机构主页为准。
